# dataset

数据集导入导出库，供数据故事平台以库的形式调用（无接口层）。数据集持久化在 SQLite。

## 功能

- 从 CSV 导入生成数据集，返回结构摘要（每列的列名、类型、缺失值个数）
- 按行号查看各单元格的值
- 把数据集导出成 CSV；导出的文件再导入会得到完全相同的数据集
  （列名、列类型、行数、每个单元格都一致，缺失值与空字符串不混，
  文本逐字节一致，小数按 64 位浮点值相等）

## 用法

```go
s, err := dataset.Open("data.db") // SQLite 文件路径
if err != nil { ... }
defer s.Close()

sum, err := s.ImportCSV(csvReader) // 导入，返回 *Summary
if err != nil {
    var ierr *dataset.ImportError
    if errors.As(err, &ierr) {
        // ierr.Category: not_utf8 / bad_quote / bad_line_end / empty_header /
        //   dup_header / column_count / too_many_rows / too_many_cols / empty_dataset
        // ierr.Record: 出错位置的记录序号（表头为 0，其后第一条记录为 1）
    }
}

v, err := s.Cell(sum.ID, row, col)  // 按行号（0 起）读单元格，v.Null 表示缺失
err = s.ExportCSV(w, sum.ID)        // 导出 CSV
sum, err = s.SummaryOf(sum.ID)      // 重新读取结构摘要
```

## CSV 格式规则

- 分隔符是逗号；行尾可以是 LF 或 CRLF，同一文件里可以混用；文件开头的 UTF-8 BOM 忽略
- 文件末尾的一个换行不产生新行，其余空行都算一行数据
- 含逗号、引号、换行的单元格用双引号包住，内部的引号写成两个；引号内的回车和换行原样属于单元格内容
- 未加引号的单元格里出现引号、闭合引号后紧跟其他字符、引号到文件结束都没闭合，整份拒收
- 空单元格是缺失值；带引号的空串 `""` 是空字符串，不是缺失值
- 第一行是表头，列名不能为空、不能重复（区分大小写）；每行列数必须与表头相同
- 数据最多 10000 行、50 列，正好到上限可以导入
- 文件不是合法 UTF-8 或违反格式规则时整份拒收，不留下半个数据集

## 类型识别

- 整数：可带负号，不能带正号或千分位，不能有多余前导零（`0` 本身可以），须在 64 位有符号范围内
- 小数：可带负号，必须有小数点且两侧都至少一位数字，整数部分无多余前导零，可跟指数
  （如 `1.5e-3`、`2.0E+10`）；须在 64 位浮点范围内；NaN、Inf、十六进制写法不算
- 日期：`月/日/四位年`，月和日可写一位或两位，必须是真实存在的日期
- 数字或日期前后带空格的不算，按文本处理；文本的首尾空格原样保留
- 一列中所有非缺失值都是整数 → 整数列；都是整数或小数 → 小数列；都是日期 → 日期列；
  其余情况（包括整列缺失）→ 文本列

## 测试

```sh
go test ./...
```

覆盖每条格式和类型规则的接受/拒收用例、随机数据集（混入逗号、引号、回车、换行、
首尾空格、空字符串、缺失值、极大极小小数、闰日、整数写法的小数、单列数据集）的
导出再导入一致性，以及上限规模（10000 行 × 50 列）导入导出各自 3 秒内完成的性能用例。
