# dataset

数据集导入导出库（Go），供上层数据故事平台以库方式调用，无接口层。
数据集持久化于 SQLite（纯 Go 驱动 `modernc.org/sqlite`，无需 cgo）。

## 功能

- 从 CSV 导入生成数据集，返回结构摘要（每列：列名、类型、缺失值个数）
- 按行号查看各单元格的值（区分缺失值与空字符串）
- 导出为 CSV；导出的文件再导入得到完全相同的数据集
- 格式违规整份拒收，报告原因类别与出错记录序号（表头为 0），不留半个数据集

## API

```go
st, _ := dataset.Open("data.db")   // 或 ":memory:"
defer st.Close()

ds, err := st.Import("名称", csvBytes) // ds: 列名/类型/缺失数/行数
if ie, ok := err.(*dataset.ImportError); ok {
    // ie.Category: encoding / syntax / header / shape / limit
    // ie.Record:   出错记录序号（表头为 0）
}

row, _ := st.Row(ds.ID, 0)        // 第 0 行全部单元格
cell, _ := st.Cell(ds.ID, 0, 1)   // 单个单元格（Cell.Null 区分缺失）
out, _ := st.Export(ds.ID)        // 导出 CSV 字节流
sum, _ := st.Summary(ds.ID)       // 结构摘要
```

## 规则要点

- 逗号分隔；行尾 LF/CRLF 可混用；开头 UTF-8 BOM 忽略；末尾一个换行不产生新行，其余空行算一条记录
- 引号规则严格：未加引号的单元格出现引号、闭合引号后跟其他字符、引号未闭合，均拒收
- 空单元格 = 缺失值；`""` = 空字符串
- 表头列名非空且不重复（区分大小写）；每行列数与表头一致；上限 10000 行 × 50 列（含边界）
- 类型：整数（int64，无多余前导零、无正号/千分位）、小数（必有小数点，可带指数，float64 范围内）、
  日期（月/日/四位年，须真实存在）；前后带空格一律按文本；整列缺失为文本列
- 全文必须是合法 UTF-8
